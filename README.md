# web-design-samples

AI（Claude Code）と一緒に作った、ホームページの制作見本です。お店もイベントも、すべて架空です。

- `cafe/` … 珈琲と焼き菓子の喫茶店「ひだまり」（架空）。写真と文章を中心にした1ページ
- `festival/` … 夜の音楽フェス「NOCTURNE 2027」（架空）。動きを中心にした1ページ

文章とデザインの無断転載はご遠慮ください。写真は Unsplash（Unsplash License）です。撮影者は `cafe/credits.html` に載せています。
フォントは Google Fonts、動きは GSAP と Lenis を使っています。
